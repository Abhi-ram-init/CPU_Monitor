# Nissan GT-R (R34) CPU & RAM Monitor

A stylish desktop system telemetry widget featuring animated Nissan Skyline GT-R (R34) dynamics with real-time CPU and RAM usage tracking.

## 🏎️ Features
- **Real-Time Telemetry**: Accurately tracks live CPU load and RAM consumption.
- **Dynamic Wheel Rotation**: Wheel spin velocity dynamically scales with CPU utilization.
- **Dynamic Swaying**: Subtle vehicle body physics and pitch effects.
- **Minimalist Aesthetic**: High-contrast black and white styling designed for transparent desktop integration.
- **Taskbar & System Tray Integration**: Minimizes unobtrusively to system tray.
- **Standalone Executable**: Includes pre-compiled `GTRMonitor.exe` ready to run without Python dependencies.

## 🚀 Getting Started

### Prerequisites
- Windows 10 / 11
- Python 3.10+ (if running from source)

### Installation (Source)
`ash
cd CPU_Monitor
pip install -r requirements.txt
python main.py
`

### Running Standalone
Launch `GTRMonitor.exe` directly from the project directory.
